# LinkProof para Windows

[Baixar o ZIP portátil mais recente](https://github.com/MaxwellNeves/LinkProof-Downloads/releases/download/v0.4.0-rc1/LinkProof-Windows.zip)

Extraia a pasta `LinkProof` inteira do ZIP e execute `LinkProof.exe` dentro dela. Mantenha os demais arquivos e pastas ao lado do executável.

Este repositório público contém somente os downloads. O código-fonte fica em um repositório privado. Os pacotes são gerados e verificados em um runner Windows do GitHub Actions. Os testes físicos em Windows e os cenários de campo ainda estão pendentes; consulte as notas de cada release antes de usar.
